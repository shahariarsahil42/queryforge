# QueryForge

A cross-database performance benchmarking and query optimization platform.

## About
QueryForge is a software engineering project designed to analyze and compare database performance across PostgreSQL and MongoDB.

## Technologies
- Python
- FastAPI
- pytest
- PostgreSQL (planned)
- MongoDB (planned)
- Docker (planned)

## Completed Features
- FastAPI backend
- Health-check endpoint
- Two automated API tests

## Installation

Install dependencies:

    python -m pip install -r requirements.txt

Start the server:

    python -m uvicorn app.main:app --reload

Run tests:

    python -m pytest -v
